# Desktop Calendar

윈도우 바탕화면에서 바로 보고 수정하는 **Google 캘린더 위젯**입니다.

- 바탕화면 오른쪽 아래의 **동그란 버블**(오늘 날짜)을 누르면 캘린더가 열리고, 다시 누르면 닫힙니다.
- 버블은 바탕화면에 붙어 있어서 "바탕 화면 보기"(Win+D)를 해도 사라지지 않습니다.
- Google 캘린더와 양방향으로 동기화됩니다. 여기서 바꾼 내용은 바로 반영되고, 폰에서 바꾼 내용도 몇 분 안에 들어옵니다.

> 이 저장소에는 설치 파일, [소개 페이지](https://kwakssi38.github.io/desktop-calendar-site/), [개인정보처리방침](https://kwakssi38.github.io/desktop-calendar-site/privacy.html)만 있습니다.

## 설치

1. [최신 릴리스](https://github.com/KwakSsi38/desktop-calendar-site/releases/latest)에서 `Desktop-Calendar-Setup-x.y.z.exe`를 받아 실행합니다.
2. 서명하지 않은 앱이라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
3. 설치가 끝나면 바로 실행되고, 윈도우를 켤 때도 자동으로 실행됩니다(트레이 메뉴에서 끌 수 있음).
4. 새 버전은 **자동으로 업데이트**됩니다. 앱이 6시간마다 확인해서 받아 두고, 앱이 꺼질 때 설치합니다.

## 처음 설정: Google Cloud에서 내 OAuth 클라이언트 만들기

이 앱은 서버가 없어서, 각자 자기 Google Cloud 프로젝트의 OAuth 클라이언트로 로그인합니다. 처음 한 번만 하면 됩니다(10분 정도, 무료).

1. [Google Cloud Console](https://console.cloud.google.com/projectcreate)에서 새 프로젝트를 만듭니다.
2. [Google Calendar API](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com)를 **사용 설정**합니다.
3. [Google 인증 플랫폼 → 브랜딩](https://console.cloud.google.com/auth/branding)에서 앱 이름과 지원 이메일, 개발자 연락처를 입력합니다.
   - 로고는 올리지 마세요. 올리면 Google의 인증 심사가 필요해집니다.
4. [대상](https://console.cloud.google.com/auth/audience)에서 사용자 유형을 **외부**로 정하고, **테스트 사용자**에 캘린더가 있는 내 Google 계정을 추가합니다.
5. [클라이언트](https://console.cloud.google.com/auth/clients)에서 **클라이언트 만들기 → 애플리케이션 유형: 데스크톱 앱**을 고르고, 만든 뒤 **JSON 다운로드**를 누릅니다.
6. 받은 파일 이름을 `credentials.json`으로 바꿔 아래 폴더에 넣습니다. 앱의 첫 화면에도 이 폴더 경로가 나옵니다.

   ```
   %APPDATA%\desktop-calendar\
   ```

   - 윈도우가 확장자를 숨기면 `credentials.json.json`이 되기 쉬우니 주의하세요.
7. 앱에서 **다시 확인 → Google로 로그인**을 누르고 브라우저에서 권한을 허용합니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동**을 누르세요. 내가 만든 클라이언트라 괜찮습니다.

### 7일마다 다시 로그인하지 않으려면

"테스트" 상태의 앱은 로그인이 7일 뒤 만료됩니다. 만료되면 버블이 회색 + 노란 느낌표로 바뀌고 알림이 뜨니, 눌러서 다시 로그인하면 됩니다.

이 과정을 없애려면 [대상](https://console.cloud.google.com/auth/audience)에서 **앱 게시**를 누르세요. 그 전에 브랜딩 화면에 홈페이지와 개인정보처리방침 주소를 넣어야 하는데, 이 저장소의 페이지 주소를 그대로 써도 됩니다.

- 홈페이지: `https://kwakssi38.github.io/desktop-calendar-site/`
- 개인정보처리방침: `https://kwakssi38.github.io/desktop-calendar-site/privacy.html`
- 서비스 약관(선택): `https://kwakssi38.github.io/desktop-calendar-site/terms.html`
- 승인된 도메인: `kwakssi38.github.io`

게시한 뒤 앱에서 로그아웃하고 다시 로그인하면, 그 뒤로는 만료되지 않습니다.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 캘린더 열기/닫기 | 버블 클릭, 트레이 아이콘 클릭, 또는 어디서든 **Ctrl+Alt+C** |
| 일정 빨리 추가 | **Ctrl+Alt+N** 또는 ＋ 버튼 → `다음주 금요일 오후 3시 회의`처럼 입력 → Enter |
| 일정 만들기 | 빈 칸 클릭. 주·일 보기에서는 끌어서 시간 범위를, 월 보기에서는 여러 날짜를 끌어서 종일 일정을 만듭니다 |
| 일정 복제 | **Ctrl을 누른 채 끌기**, 또는 편집 창의 **복제** 버튼 |
| 일정 옮기기 / 길이 바꾸기 | 일정을 끌어서 다른 날짜·시간으로. 주·일 보기에서는 아래쪽 끝을 끌면 길이가 바뀝니다(15분 단위) |
| 되돌리기 | 변경 후 7초 동안 뜨는 "실행 취소" 또는 **Ctrl+Z** |
| 검색 | ⌕ 버튼 또는 **/** |
| 빈 시간 알려주기 | ☰ 아래 **빈 시간 공유** 또는 **F** → 기간과 시간대를 고르고 **복사**. `10/23(금) 18:00–22:00` 같은 글이 복사됩니다 |
| 캘린더 켜고 끄기, 설정 | ☰ 버튼 |
| 메뉴 (새로고침, 자동 실행, 로그아웃, 종료) | 트레이 아이콘이나 버블을 오른쪽 클릭 |

### 캘린더 창 안의 단축키

입력칸에 글자를 치는 중에는 동작하지 않습니다.

| 키 | 동작 |
|---|---|
| `T` | 오늘로 |
| `←` `→` (또는 `K` `J`) | 이전 / 다음 |
| `M` `W` `X` `D` `A` | 월 / 주 / 3일 / 일 / 일정 목록 보기 |
| `N` | 빠른 추가 |
| `/` | 검색 |
| `F` | 빈 시간 공유 |
| `Esc` | 열린 창 닫기, 아무것도 없으면 캘린더 닫기 |

### 빠른 추가 문법

`[캘린더 이름] 날짜 시간 제목` 순서로 자유롭게 씁니다. 입력하는 동안 어떻게 해석했는지 미리보기가 나옵니다.

| 종류 | 예시 |
|---|---|
| 캘린더 | `[개발]`, `[학교 과제]`. 빼면 기본 캘린더에 들어갑니다 |
| 날짜 | `오늘` `내일` `모레` `글피`, `3일 후`, `2주 뒤`, `일주일 뒤`, `보름 후`, `한 달 뒤`, `3개월 후`, `금요일`, `다음주 금요일`, `10월 25일`, `11/2`, `2026-12-24`, `25일`, `다음 달 5일` |
| 요일 | 시간 앞에 쓴 한 글자 요일(`금 3시`), `주말`. `금 시세`처럼 시간이 뒤따르지 않으면 요일로 읽지 않습니다 |
| 반복 | `매일`, `매주`, `매주 화목`, `월수금 7시`, `격주 화요일`, `3주마다`, `평일`, `매달 25일`, `매년 12월 25일`, `2일마다` |
| 음력 | `음력 3월 5일`, `매년 음력 9월 9일`(앞으로 10년치를 만들고, 지울 때 한꺼번에 지울 수 있음) |
| 시간 | `오후 3시`, `3시 반`, `14:30`, `3시~5시`, `9-6시`, `오후 3-5시`, `오전 10시부터 12시까지`, `밤 11시~1시` |
| 길이 | `2시간`. 따로 쓰지 않으면 1시간 |
| 종일 | 시간을 쓰지 않거나 `종일`을 붙이면 종일 일정 |

- `오전`/`오후` 없이 쓴 1~7시는 **오후**로 읽습니다. `3시 회의`는 15:00입니다.
- `[`를 치면 `]`가 자동으로 함께 생깁니다.

## 기능

- **보기:** 월, 주, 3일, 일, 일정 목록. 여러 날 일정은 이어진 막대로, 겹치는 일정은 나란히 표시합니다.
- **편집 창:** 일정 색(11가지), 알림, 반복(매일, 매주, 평일, 매월, 매년, 매년 음력), D-day 표시, 화상회의 참여와 지도 버튼, 복제.
- **반복 일정:** 수정, 삭제, 이동할 때 "이 일정" 또는 "모든 반복 일정"을 고릅니다.
- **알림:** Google에 설정한 알림 시간에 윈도우 알림을 띄웁니다(따로 없으면 10분 전). 알림을 누르면 5분, 10분, 30분, 1시간 후, 시작할 때 중에서 **다시 알림**을 고르거나 회의에 바로 참여할 수 있습니다. 앱이 켜져 있을 때만 울립니다.
- **공휴일:** 대한민국 공휴일은 날짜와 이름을 빨갛게, 기념일은 이름만 회색으로 표시합니다. Google 캘린더 목록에 공휴일 캘린더를 추가하지 않아도 됩니다.
- **버블:** 화상회의가 있는 일정은 시작 5분 전부터 끝날 때까지 **참여** 버튼이 나옵니다. D-day로 표시한 가장 가까운 일정도 보여줍니다. 오늘 남은 일정 수를 빨간 배지로, 15분 안에 시작하는 일정은 노란 테두리로 보여줍니다. 마우스를 올리면 진행 중인 일정과 다음 일정이 보입니다.
- **빈 시간 공유:** 다음 3·7·14일 중 원하는 시간대의 빈 시간을 글로 복사합니다. 캘린더에 적지 않는 **평소 일정**(`금 9-6시 회사`, `평일 12-1시 점심`)을 적어 두면 그 시간도 바쁜 시간으로 칩니다. 평소 일정은 이 PC에만 저장됩니다.
- **D-day:** 편집 창에서 "D-day 표시"를 켜면 일정 앞과 버블에 `D-12`처럼 남은 날을 보여줍니다.
- **오프라인:** 마지막으로 받은 일정을 저장해 두고, 인터넷이 없을 때도 보여줍니다.
- **설정:** 글꼴(설치된 글꼴 선택 가능), 글자 크기, 한 주 시작 요일, 공휴일 표시(공휴일과 기념일 / 공휴일만 / 표시 안 함), 동기화 주기(1/2/5분), 테마(시스템/라이트/다크).

## 개인정보

- 일정과 로그인 정보는 **내 PC에만** 저장되고, 앱은 Google 캘린더 API와만 통신합니다. 개발자 서버는 없습니다.
- 로그인 토큰은 윈도우 데이터 보호(DPAPI)로 암호화해 `%APPDATA%\desktop-calendar\`에 저장합니다.
- 사용하는 권한: `calendar.events`(일정 보기·수정), `calendar.calendarlist.readonly`(캘린더 목록)
- 연결 해제: 트레이 메뉴 → **로그아웃**, 또는 [Google 계정 → 서드파티 액세스](https://myaccount.google.com/permissions)에서 권한 삭제.

자세한 내용은 [개인정보처리방침](https://kwakssi38.github.io/desktop-calendar-site/privacy.html)과 [서비스 약관](https://kwakssi38.github.io/desktop-calendar-site/terms.html)을 참고하세요.

## 알려진 한계

- 윈도우 전용입니다.
- 버블은 주 모니터 오른쪽 아래에 고정돼 있습니다.
- 반복 일정은 "이 일정 및 향후 일정" 범위를 지원하지 않습니다.
- 전역 단축키(Ctrl+Alt+C, Ctrl+Alt+N)는 아직 바꿀 수 없습니다. 다른 앱이 먼저 쓰고 있으면 트레이 메뉴에 "사용 중"으로 표시됩니다.
