개인정보처리방침

Desktop Calendar · 시행일 2026년 10월 22일

1. 수집하는 정보

Desktop Calendar(이하 "앱")는 개발자가 운영하는 서버가 없으며, 사용자의 개인정보를 수집하거나 외부로 전송하지 않습니다.

2. Google 사용자 데이터의 사용

앱은 사용자가 로그인하면 아래 권한으로 Google 캘린더 API에 직접 접근합니다.

  • https://www.googleapis.com/auth/calendar.events: 일정을 보여주고, 사용자가 요청할 때 일정을 추가, 수정, 삭제합니다.
  • https://www.googleapis.com/auth/calendar.calendarlist.readonly: 캘린더 목록과 색을 표시합니다.

이 데이터는 사용자의 화면에 캘린더를 표시하고 알림을 띄우는 데에만 쓰입니다. 광고, 분석, AI 모델 학습에 쓰지 않으며 제3자에게 판매하거나 공유하지 않습니다. 앱의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 사용자 PC에 저장하는 정보

  • 로그인 토큰: 윈도우 데이터 보호(DPAPI)로 암호화해 %APPDATA%\desktop-calendar\에 저장합니다.
  • 오프라인 표시용 일정 사본과 화면 설정: 같은 PC의 앱 데이터 폴더에만 저장합니다.

4. 데이터 삭제와 접근 철회

  • 앱의 트레이 메뉴에서 로그아웃을 누르면 저장된 토큰을 삭제합니다.
  • Google 계정 → 보안 → 서드파티 액세스에서 언제든 앱의 접근 권한을 해제할 수 있습니다.
  • 앱을 제거한 뒤 %APPDATA%\desktop-calendar\ 폴더를 지우면 PC에 남은 데이터가 모두 삭제됩니다.
